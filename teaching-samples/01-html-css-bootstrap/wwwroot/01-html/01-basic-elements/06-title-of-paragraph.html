About this course

The course covers:

How the web works: clients, servers and the HTTP protocol; describing the content of web pages with HTML; describing the look of web pages with CSS; responsive pages with the Bootstrap framework.

Procedural and object-oriented programming in Python; building web applications with FastAPI, where the pages are produced on the server from Jinja2 templates.

The REST architectural style, HTTP methods and status codes, the JSON format; building and consuming RESTful services with FastAPI.

The relational model, the SQL language, the SQLite and PostgreSQL database management systems; accessing a database from Python.

If you move the pointer over a paragraph, its title appears in a tooltip.
