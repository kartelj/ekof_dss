Developing Software Solutions

Python edition

Aim and objectives

The objective of this course is to develop and broaden student competences in the basic components of information systems development, in development concepts in Python, in service oriented solutions and in modern software architectures.

Students will be able to explain the basic components of information systems development; to build dynamic web sites, applications and services with FastAPI, an open-source web framework for Python; to use a programming model organized around objects; to apply modular programming; and to implement a service oriented architecture.
