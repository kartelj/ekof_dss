# Assignment: the API of the films - a solution

The assignment of the lecture *Introduction to REST APIs*: design a REST API for the films of
the database VanityFair02 - the resources and their addresses, the JSON of a film, every
operation with its request and its answers, and which requests are safe and idempotent.

The solution is the design document [movies-api.md](movies-api.md). Nothing has to be run.

The assignment of the next lecture builds this API with FastAPI: [06-02-fastapi-rest](../06-02-fastapi-rest/).
Every answer in the document is the real answer of that service, started with its original data.
