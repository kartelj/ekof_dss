# Exercises

The lectures and the practice go together. After every topic, a lecture has a short exercise on what it has
shown so far - the slides with a green title. The button *Solution* on the slide shows a solution (on GitHub it is
a section that opens with a click). Every lecture ends with a larger assignment, of about 30 to 45 minutes, that
uses the whole lecture.

This folder holds the solutions of the assignments, one folder per lecture. Every folder has a `README.md` with
the task in brief, how to open or run the solution, and the expected results.
